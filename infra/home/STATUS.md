## Проверенные ограничения и следующий этап

1. Quick Tunnel годится только для теста. Нужен именованный туннель и постоянный адрес API.
2. Туннель использует HTTP/2; исходящая связь Cloudflare прошла встроенные проверки.
3. Docker-контейнеры имеют restart: unless-stopped. Запуск Windows/WSL2/Docker после перезагрузки, отсутствие сна и восстановление после потери питания не проверены.
4. Соседние контейнеры, DNS сайтов и почтовые записи не изменялись.
5. Секреты и БД не создавались и не публиковались.
6. Без исходной БД нельзя восстановить прежние километры и участников. Новую серверную логику и согласованные backup нужно строить отдельно.
7. Первый запуск исчерпал лимит команды после загрузки образов, на ожидании healthcheck. Проверено, что фоновых заданий не осталось; повторный compose up завершился успешно.
8. safe-edit не смог создать временный файл на Windows-диске D. Обычная запись Python в этот же разрешённый каталог сработала; права и политика агента не изменялись.

## Остановка теста

```sh
cd /mnt/d/Projects/sportfond-home
docker compose down
```

Удаляется только этот тестовый compose-проект. Временный публичный адрес перестанет работать.
